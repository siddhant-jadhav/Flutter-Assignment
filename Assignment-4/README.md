# Flutter Responsive Dashboard

A simple Flutter dashboard demonstrating **responsive UI design** and different Flutter layout widgets.

## Features

* Responsive layout using `MediaQuery`
* Horizontal category `ListView`
* Responsive `GridView` for statistics
* `Expanded` and `Flexible` layouts
* Vertical `ListView` for recent activities
* Material 3 UI
* Adapts between mobile and tablet/desktop screens

## Concepts Used

* `MediaQuery`
* `ListView`
* `GridView`
* `Expanded`
* `Flexible`
* `StatefulWidget`
* `setState()`
* `SingleChildScrollView`
* `Card` and `ListTile`

## How to Run

```bash
flutter pub get
flutter run
```

## Dashboard Sections

1. Welcome Banner
2. Quick Categories
3. Overview Metrics
4. Performance & Target
5. Recent Activities
