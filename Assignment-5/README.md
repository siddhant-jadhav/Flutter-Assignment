# Flutter Stateful Todo List

A Flutter Todo List app demonstrating **StatefulWidget, setState(), filtering, and task management**.

## Features

* Add new tasks with priority levels.
* Mark tasks as completed.
* Delete tasks with Undo option.
* Filter tasks by All, Pending, and Completed.
* Clear all completed tasks.
* Shows task progress and completion percentage.
* Swipe-to-delete functionality.
* Uses an in-memory Todo list.

## Concepts Used

* `StatefulWidget`
* `setState()`
* `ListView`
* `Dismissible`
* `ChoiceChip`
* `showModalBottomSheet`
* `SnackBar`
* `enum`
* Flutter state management

## How to Run

```bash
flutter pub get
flutter run
```
