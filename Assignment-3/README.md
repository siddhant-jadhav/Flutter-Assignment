# Flutter Profile UI

A Flutter profile screen demonstrating **custom UI design, reusable widgets, layout composition, theming, and interactive state management**.

## Features

* Profile avatar with verification badge
* Name, role, and bio section
* Projects, followers, and rating statistics
* Contact and profile information
* Follow / Unfollow functionality
* Message and Share buttons
* Responsive centered profile card
* Material 3 themed UI

## Concepts Used

* `StatefulWidget`
* `setState()`
* `Scaffold` and `AppBar`
* `Container`, `Row`, `Column`, and `Stack`
* `CircleAvatar`
* `ElevatedButton` & `OutlinedButton`
* Custom reusable helper widgets
* `Theme.of(context)` and `ColorScheme`

## How to Run

```bash
flutter pub get
flutter run
```
