# Flutter Product Listing

A Flutter product catalog app demonstrating **ListView.builder, StatefulWidget, filtering, searching, sorting, and dynamic product management**.

## Features

* Search products by name, description, or category.
* Filter by product category.
* Sort by price, rating, or name.
* Filter favorite products.
* Add and delete products dynamically.
* Add products using a form.
* Add products to cart.
* Display product ratings, prices, discounts, and stock status.
* Reset all filters.

## Concepts Used

* `StatefulWidget`
* `setState()`
* `ListView.builder`
* `TextField`
* `FilterChip`
* `PopupMenuButton`
* `showModalBottomSheet`
* `Form` & validation
* Enums and data models
* Dynamic filtering and sorting

## How to Run

```bash
flutter pub get
flutter run
```
